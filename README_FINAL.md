### Common Issues:
| Issue | Solution |
|-------|----------|
| Port in use | Kill process: `lsof -ti:PORT \| xargs kill -9` |
| CORS error | Check backend CORS_ORIGIN |
| Map not showing | Clear browser cache, restart |
| Real-time not working | Check Socket.IO connection |
